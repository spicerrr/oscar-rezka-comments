# Data publication policy

This directory intentionally excludes:

- `comments_raw.csv` and `comments_raw.jsonl`;
- raw AJAX response pages;
- `films_resolved.csv` and collection logs;
- browser sessions and cookies;
- author salts;
- Ollama checkpoints and job manifests;
- failed or partial full-corpus exports.

Files that may be published:

- `films_master.csv`: the fixed list of 28 films;
- `comments_sample_2555.csv`: the reproducible analytical sample;
- `sample_2555_v4_labeled_ollama.csv`: completed labels for the sample.

The sample still contains public user-generated text. Before publication,
review the platform terms and the institutional research-ethics requirements.
